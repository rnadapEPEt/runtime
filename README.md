# Exercícios de Python com apoio do Copilot

Coleção de pequenas soluções em Python escritas durante os estudos, com o Copilot apenas sugerindo trechos.

### Antes de começar

Se você não tem assinatura do Copilot, tudo bem: dá para usar qualquer assistente de código disponível na web como apoio de estudo.

## 1 - Juntando duas entradas

Objetivo: pedir dois valores distintos ao usuário e devolver os dois colados em um único texto.

Pontos praticados:

* trabalho com texto (str)
* junção de trechos
* leitura do teclado
* uso consciente das sugestões da ferramenta

<br>

## 2 - Texto repetido N vezes

Objetivo: receber uma palavra e um número, devolvendo a palavra repetida tantas vezes quanto foi pedido.

Pontos praticados:

* trabalho com texto (str)
* valores inteiros (int)
* repetição controlada
* leitura do teclado
* revisão das propostas automáticas

<br>

## 3 - Conta simples entre dois números

Objetivo: ler dois números e aplicar uma operação aritmética entre eles.

Pontos praticados:

* operações básicas
* leitura do teclado
* revisão das propostas automáticas

<br>

## 4 - Par ou ímpar

Objetivo: ler um inteiro e dizer se ele é par ou ímpar. A ideia é usar desvio condicional e, se quiser, pedir ao assistente uma versão mais curta do mesmo código.

Pontos praticados:
* uso de if e else para decidir
* noção de resto da divisão para descobrir a paridade
* comparação entre a solução escrita à mão e a sugerida pela ferramenta

<br>

## 5 - Média de três notas

Objetivo: calcular a média aritmética de três notas informadas pelo usuário. Basta usar os operadores de soma e divisão.

Pontos praticados:
* guardar os valores lidos em variáveis
* operadores aritméticos para a média
* prática de entrada e tratamento de dados

<br>

## 6 - Palavras que se leem igual ao contrário

Objetivo: descobrir se uma palavra é um palíndromo. A dica é inverter o texto e comparar com o original.

Pontos praticados:
* manipulação de texto em Python, em especial a inversão
* comparação entre a palavra e a sua versão de trás para frente
* noção do conceito de palíndromo e onde ele aparece em exercícios

* Repare que a saida pode variar conforme a versao do runtime.
